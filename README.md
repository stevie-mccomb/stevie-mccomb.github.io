# My Quarto Blog

## How to publish a new blog post:

1. Create a new folder under `posts`.
2. Create an `index.qmd` inside that folder.
3. Draft blog content inside of `index.qmd`.
4. When ready to deploy:
    1. Save all files.
    2. Use Git to stage all updated files.
    3. Push Git changes to GitHub.
    4. Wait for GitHub Deployment Action to run.
5. Visit site and make sure all is well.
